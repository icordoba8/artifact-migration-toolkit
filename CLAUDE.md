## Ponytail
Ponytail is always on in this repo, mode: full. For every code change, apply the `ponytail` skill (.claude/skills/ponytail/SKILL.md): write the minimum code that solves the task and mark deferred shortcuts with `shortcut:` comments.
When delegating to a subagent, tell it to follow .claude/skills/ponytail/SKILL.md in full mode.
The plugin hooks, band/task board, PONYTAIL_DEFAULT_MODE and ~/.config/ponytail/config.json are not installed here; ignore any skill step that depends on them.
